常见问题

妙笔是开源的吗？

软件本体闭源（本仓库只放官网、规则池和发布包）；规则池数据开源共建。

我的文章数据会上传吗？

不会。文章、密钥、缓存全部留在本机；唯一的外联是 LLM 中转调用和你主动触发的规则池拉取/更新检查。

需要什么网络环境？

写作走你自己的 Claude 兼容中转线路（线路池测速择优）；规则池同步走公共 CDN，普通网络即可。

支持 Mac / Linux 吗？

当前为 Windows 版，Mac/Linux 在计划中。

怎么获得激活码？

本地模式开箱即用全部功能；离线激活码面向发行渠道，联系维护者获取。
