常见问题

妙笔是开源的吗？

软件本体闭源（官网仓库只放页面、规则池和发布包）；规则池数据开源共建。

我的文章数据会上传吗？

不会。文章、密钥、缓存全部留在本机；唯一的外联是 LLM 中转调用和你主动触发的规则池拉取/更新检查。

激活码怎么运作？

一机一码：激活码绑定机器指纹，离线签发生效；名单机制支持远程吊销，换机联系维护者补发。

算力费用怎么算？

软件只收授权费。写作走你自己的 Claude 兼容中转线路，按量计费、不用不扣——密钥存本机，不经我们手。

需要什么网络环境？

写作走中转线路（线路池测速择优，支持自定义供应商）；规则池同步走公共 CDN，普通网络即可。

支持 Mac / Linux 吗？

当前为 Windows 版，Mac/Linux 在计划中。
